# Rock-Paper-Scissors

I built a simple Rock Paper Scissors Game which can be played in the console.

Game Rules: 
    - Type your choice from the three choices given. 
    - In one game - there are three rounds and reach round has round winner and after 5 rounds the competitor with higher score wins
    - *Rock Beats Scissors*
    - *Scissors Beats Paper*
    - *Paper Beats Rock*

Key Learnings:
    - functions , function parameters & arguments
    - Scope : Global scope & Local scope
    - Reading and solving Errors like type errors, syntax errors, reference errors & logical errors 
    - Writing Plan and pseudocode before coding
